# CarFly

Een 3D-project in de browser, gemaakt met [Three.js](https://threejs.org/) en [Vite](https://vite.dev/).

## Starten

```bash
npm install
npm run dev
```

Open daarna de link in de terminal (meestal http://localhost:5173).

## Werkwijze

1. Maak een issue met een template op GitHub.
2. Maak een branch: `githubnaam/issueN`.
3. Commit met conventional commits en `Refs #N`.
4. Sluit af met een commit met je reflectie en `Fixes #N`.
5. Open een pull request naar `main` en vraag een review.

Zie ook [AGENTS.md](AGENTS.md).
